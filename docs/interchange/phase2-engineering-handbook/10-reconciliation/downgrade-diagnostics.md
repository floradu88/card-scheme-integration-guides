# Downgrade Diagnostics

## Diagnostic output

- selected rule;
- selected fallback/downgrade flag;
- candidate preferred programs;
- unmet predicates;
- missing source fields;
- timing failure;
- data-quality confidence;
- actual network outcome.

## Safe language

Use:
- “The configured model selected…”
- “The following configured condition was not met…”
- “Actual network result differed…”

Avoid asserting undocumented network causality when private qualification logic is unavailable.

## Common categories

- late presentment;
- missing or inconsistent authorization linkage;
- fallback/manual entry;
- authentication indicator absent;
- incomplete Level II/III data;
- card product misclassification;
- incorrect MCC/country;
- unsupported transaction subtype;
- stale configuration.
