# Research Findings from Official Public Sources

## Visa

The current public Visa Core Rules and Product and Service Rules provide the governing framework and regional applicability, but explicitly omit proprietary, competitive and security-sensitive details. The current public edition found during this work is dated April 18, 2026.

VisaNet Connect Acceptance provides a public REST-oriented integration surface for approved participants. The public documentation states that it uses ISO 20022/ATICA naming, provides a sandbox, and requires mutual authentication for API access.

Visa also publishes merchant-data standards and, for some markets such as the United States, public interchange reimbursement fee schedules. These are useful source inputs but do not constitute a complete global qualification implementation.

## Mastercard

Mastercard publishes Rules, Transaction Processing Rules, Switch Rules, Security Rules and regional interchange hubs. The current Mastercard Rules found are dated June 2, 2026; the public Transaction Processing Rules found are dated December 9, 2025.

Mastercard's US interchange hub states that each interchange rate has requirements that must all be satisfied and exposes supporting merchant-category, criteria and glossary material. Europe has regional rate and regulatory material.

## Engineering implication

A production engine must use a source-adapter model and authorized internal documentation. Public documents are the governance foundation and source index—not a substitute for proprietary message specifications and certification artifacts.
