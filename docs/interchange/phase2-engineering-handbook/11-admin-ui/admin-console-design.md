# Admin Console Design

## Pages

1. Dashboard.
2. Source registry.
3. Packages.
4. Programs.
5. Rules.
6. Rate tables.
7. Dictionaries.
8. Overrides.
9. Validation report.
10. Simulation.
11. Version diff.
12. Approval and activation.
13. Reconciliation explorer.
14. Audit log.

## Rule editor

- form-based conditions;
- no arbitrary scripts;
- live partition and specificity preview;
- overlap warnings;
- source citation required;
- generated human-readable sentence;
- embedded positive/negative tests.

## Import screen

Show:
- file checksum;
- detected network/region/version;
- added/changed/removed counts;
- validation errors;
- portfolio impact;
- candidate-count/performance impact;
- approval state.

## Activation

Require:
- approved package;
- scheduled effective time;
- target environment;
- checksum confirmation;
- rollback package;
- node preload health.

## Access

Separate permissions for:
- view;
- author;
- import;
- approve;
- activate;
- export proprietary content;
- emergency rollback.
