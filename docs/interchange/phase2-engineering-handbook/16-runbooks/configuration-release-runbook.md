# Configuration Release Runbook

1. Register source publication.
2. Record publication/effective dates and access classification.
3. Create draft package.
4. Import and normalize.
5. Resolve validation findings.
6. Run golden tests.
7. Run historical impact simulation.
8. Review rate and coverage changes.
9. Obtain independent approval.
10. Schedule activation.
11. Preload all nodes.
12. Activate atomically.
13. Confirm active checksum.
14. Monitor fallback, unmatched, variance and latency.
15. Close release with evidence package.
