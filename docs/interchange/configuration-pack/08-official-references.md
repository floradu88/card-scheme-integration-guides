## Documentation boundary

The public Visa rules explicitly note that proprietary, competitive and security-sensitive details may be omitted. Exact VisaNet and Mastercard message specifications, network program identifiers, private bulletins, certification material and detailed regional qualification guides may require authorized participant access.

Store an internal source index for every imported package, including document title, publication date, effective date, region, network, internal access location and checksum.
