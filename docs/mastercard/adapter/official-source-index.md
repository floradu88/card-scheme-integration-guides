## Public-source limitations

Mastercard public rules and interchange hubs do not replace customer implementation manuals, private bulletins, settlement file specifications, or portal-only interchange manuals.

## Required internal source registry fields

- network;
- document title;
- edition/publication date;
- announced effective date;
- region/country;
- public/private classification;
- authorized repository location;
- checksum;
- owner;
- superseded-by relationship;
- extracted configuration package IDs.
