# PCI DSS 4.0.1 Plan

## Scope
- Define the cardholder data environment.
- Build data-flow and network diagrams.
- Inventory systems, people, processes, and third parties.
- Validate segmentation.

## Control domains
1. Network security controls
2. Secure configurations
3. Stored account data protection
4. Encryption in transit
5. Malware protection
6. Secure systems and software
7. Need-to-know access
8. User identification and authentication
9. Physical access
10. Logging and monitoring
11. Security testing
12. Security policy and risk management

## Evidence
- configuration standards
- scan results
- penetration tests
- access reviews
- log reviews
- key-management records
- incident response tests
- training records
- supplier compliance evidence
