# PCI Readiness Checklist

- [ ] CDE defined
- [ ] CHD/SAD flows documented
- [ ] Segmentation validated
- [ ] PAN masking enforced
- [ ] SAD not retained after authorization
- [ ] Encryption at rest and in transit verified
- [ ] Key-management procedures approved
- [ ] MFA for administrative access
- [ ] Quarterly ASV scans scheduled
- [ ] Internal scans scheduled
- [ ] Penetration testing completed
- [ ] File integrity monitoring enabled
- [ ] Daily log review or automated equivalent
- [ ] Incident-response plan tested
- [ ] QSA/SAQ route confirmed
