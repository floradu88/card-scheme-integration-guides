# Stage Gate Template

## Entry Criteria
- [ ] Scope approved
- [ ] Owners assigned
- [ ] Dependencies identified
- [ ] Risks recorded

## Activities
- [ ] Required tasks completed
- [ ] Required reviews performed
- [ ] Required tests executed

## Evidence
- [ ] Design documents
- [ ] Test reports
- [ ] Approval records
- [ ] Operational evidence
- [ ] Compliance evidence

## Exit Criteria
- [ ] No open critical defects
- [ ] High risks accepted or mitigated
- [ ] Required controls implemented
- [ ] Rollback or recovery verified
- [ ] Handover completed

## Approvals
- [ ] Architecture
- [ ] Engineering
- [ ] Security
- [ ] Operations
- [ ] Compliance
- [ ] Business

## Decision
- [ ] GO
- [ ] CONDITIONAL GO
- [ ] NO GO
