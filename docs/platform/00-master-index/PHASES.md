# Phases

## Phase 01
Business, domain, governance, architecture, and stage gates.

## Phase 02
Visa, Mastercard, network adapters, clearing, settlement, reconciliation, and certification.

## Phase 03
PCI DSS 4.0.1, GDPR, PSD2/SCA, EMV 3DS, ISO 27001, NIST CSF, OWASP, HSM, tokenization, and threat modeling.

## Phase 04
Kubernetes, Terraform, CI/CD, observability, capacity, FinOps, and software supply-chain security.

## Phase 05
Incident response, disaster recovery, runbooks, go-live, hypercare, BAU, and decommission.

## Phase 06
Schemas, SQL, OpenAPI, templates, checklists, ADRs, and diagrams.

## Phase 07
Configurable, explainable, vendor-neutral dynamic interchange decision engine (architecture, rule DSL, API, data model, testing, deployment).

## Phase 08
Visa Developer tooling, .NET implementation plan, sandbox → certification → production path, calendars, checklists, and email templates.
