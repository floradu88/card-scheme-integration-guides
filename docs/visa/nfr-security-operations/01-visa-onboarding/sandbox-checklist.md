# Visa Sandbox Checklist

## Account and project
- [ ] Organization-owned account created
- [ ] Project created
- [ ] VisaNet Connect – Acceptance selected
- [ ] Required API visible
- [ ] API version recorded
- [ ] Technical owner assigned
- [ ] Security owner assigned

## Credentials
- [ ] Client certificate downloaded
- [ ] Private key stored in vault
- [ ] Visa trust chain configured
- [ ] Credentials restricted by environment
- [ ] No credentials in Git
- [ ] Rotation owner assigned

## Connectivity
- [ ] DNS works
- [ ] Firewall route approved
- [ ] Proxy behavior tested
- [ ] Mutual TLS works
- [ ] Authentication works
- [ ] Error responses mapped
- [ ] Timeouts tested
- [ ] Logs redacted

## Functional
- [ ] Valid authorization
- [ ] Invalid request
- [ ] Authentication failure
- [ ] Timeout
- [ ] Duplicate/correlation behavior
- [ ] Reversal or void where in scope

## Exit criteria
- [ ] Sandbox report completed
- [ ] Production gaps documented
- [ ] Certification dependencies confirmed
