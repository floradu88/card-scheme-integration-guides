# Operational Readiness Checklist

## Ownership
- [ ] Business owner
- [ ] Technical owner
- [ ] Security owner
- [ ] Operations owner
- [ ] Finance/reconciliation owner
- [ ] Visa/acquirer contacts

## Architecture
- [ ] Architecture approved
- [ ] Dependencies inventoried
- [ ] Failure modes documented
- [ ] Last-known-good behavior verified

## Security
- [ ] Threat model
- [ ] Secrets in vault
- [ ] Access reviewed
- [ ] Logging redaction verified
- [ ] Vulnerability scans passed
- [ ] Penetration test completed where required

## Reliability
- [ ] SLOs approved
- [ ] Capacity test passed
- [ ] Failover tested
- [ ] DR tested
- [ ] Backups restored successfully

## Operations
- [ ] Dashboards live
- [ ] Alerts tested
- [ ] Runbooks approved
- [ ] On-call ready
- [ ] Escalation contacts verified

## Release
- [ ] Certification complete
- [ ] Rollback tested
- [ ] Shadow mode passed
- [ ] Canary plan approved
- [ ] Go-live approval recorded
