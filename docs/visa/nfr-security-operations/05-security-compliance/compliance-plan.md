# Compliance Plan

## PCI DSS

The final PCI scope depends on architecture and data handling.

Plan for:

- cardholder-data flow diagram;
- scope inventory;
- segmentation;
- access control;
- logging;
- vulnerability management;
- penetration testing;
- secure software lifecycle;
- evidence collection;
- annual/continuous compliance activities.

## GDPR and privacy

Where personal data is processed:

- lawful basis;
- minimization;
- purpose limitation;
- retention;
- data subject rights;
- processor/controller agreements;
- breach response;
- international transfer controls;
- DPIA where required.

## Visa rules and contractual controls

- current rule editions;
- Visa/acquirer implementation material;
- certification evidence;
- document access restrictions;
- audit rights;
- change-notification process;
- production support obligations.

## Internal controls

Potential controls:

- SOX-style change approval where financially material;
- four-eyes configuration approval;
- release evidence;
- segregation of duties;
- financial reconciliation;
- audit retention;
- incident reporting.

## Evidence repository

Retain:

- source document metadata;
- checksums;
- package diffs;
- approvals;
- test results;
- certification results;
- deployment evidence;
- active-version records;
- reconciliation reports;
- incident and recovery records.
