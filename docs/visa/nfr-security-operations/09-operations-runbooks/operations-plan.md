# Operations Plan

## Support model

Define:

- L1 operations;
- L2 application support;
- L3 engineering;
- security incident contact;
- Visa/acquirer escalation;
- finance/reconciliation owner;
- incident commander.

## Severity

### SEV1
Material payment outage, security compromise, duplicate financial processing, or material settlement risk.

### SEV2
Partial degradation, significant variance, certificate risk, or delayed settlement.

### SEV3
Limited issue, non-critical backlog, performance warning, or test environment failure.

## Operational routines

Daily:

- active version check;
- certificate health;
- Visa error review;
- settlement feed freshness;
- reconciliation variance;
- failed/dead-letter messages.

Weekly:

- capacity trends;
- fallback/unmatched analysis;
- privileged changes;
- vulnerability status;
- unresolved cases.

Monthly:

- SLO/error budget;
- access review;
- cost review;
- patch status;
- DR/readiness actions;
- source-document updates.
