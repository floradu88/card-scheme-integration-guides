# Visa Quick Start Stage Gates

## Sandbox
- [ ] Project/API status ready
- [ ] Correct sandbox endpoint
- [ ] Credentials loaded from secure store
- [ ] Authentication validated
- [ ] MLE validated where required
- [ ] Callback configured/ping-tested where required
- [ ] Error and timeout cases tested
- [ ] Observability complete

## Certification
- [ ] Project promoted
- [ ] Separate certification credentials
- [ ] Certification endpoint configured
- [ ] mTLS/X-Pay/MLE validated as applicable
- [ ] Required certification tests passed
- [ ] Evidence archived
- [ ] Required approvals captured

## Production
- [ ] Project production onboarding complete
- [ ] Separate production credentials
- [ ] Production endpoint configured
- [ ] Callback configuration approved where applicable
- [ ] Credential expiry alerts active
- [ ] Smoke test approved
- [ ] Monitoring/runbooks/on-call ready
- [ ] Rollback tested
- [ ] Go-live approval
