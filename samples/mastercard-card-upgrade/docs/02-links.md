## What to obtain directly from Mastercard

Ask the Mastercard issuer/implementation team for:

- Account Level Management manual
- Product Graduation Plus / Product Graduation Select documentation
- Universal Specification
- Universal Specification Submission API OpenAPI/schema
- Universal Specification Detailed Response API schema
- Sandbox and production URLs
- Product Graduation service/action codes
- Registered Product Code rules
- Reject/error codes
- effective-date rules
- certification/test cases
- production onboarding checklist

These issuer-specific materials should be treated as the canonical source for
the actual ALM wire contract.
